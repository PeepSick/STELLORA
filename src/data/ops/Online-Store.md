# Online Store

Platform: Shopify, custom theme built by a freelance dev in 2023. Ships Monday–Wednesday, roasted the same day or day prior.

Products: single origins, [[House-Blend]], gift sets, upcoming [[Subscription-Launch]] boxes, and a small merch line (mugs, tote, zine).

Fulfillment done in-house by Priya. Shippo for labels, USPS Ground Advantage default, UPS for anything over 5 lb. Average order value $ 31, ~180 orders/month.

Return rate under 1%. Most common issue: "wrong grind" (mitigated by defaulting to whole bean at checkout). Metrics roll up to [[KPIs-Dashboard]]. Revenue split in [[Financials-2025]].
