# Single Origins

We rotate 3–4 single origins at any time. Current lineup:

- Ethiopia Yirgacheffe (natural) — blueberry, jasmine, honey. Light roast. See [[Ethiopia-Origin]].
- Colombia Huila (washed) — caramel, red apple, cocoa. Medium roast. See [[Colombia-Origin]].
- Guatemala Antigua (washed) — dark chocolate, dried cherry, almond. Medium-dark.
- Kenya Nyeri (washed, seasonal) — blackcurrant, tomato, brown sugar. Medium.

Priced $17–20/12oz retail. Batches held to 6 kg on the Probat (see [[Equipment-Inventory]]). Profiles logged in [[Roasting-Profiles]] and [[Cupping-Notes]].
