# Program_yapımcısı

Program yapımcısı; yapımın oluşturulmasında tüm çalışmaları idare eden, gerekli planlamaları yapan kişidir. Yabancı[kime göre?] programların yayın haklarını satın alarak kendi ülkesinde uygular. Programla ilgili fikirleri bulur. Yapımın bütçesini belirler. Gereken mali imkânları ve malzemeleri temin eder. Yapım ekibini belirleyerek idare eder. Yazar ile program metni üzerinde çalışmalar yapar. Yapıma ilişkin yazışmaları sağlar. Canlı ve bant yayınlarda yönetmenle çalışmasında fayda vardır.
