# Microsoft_Dynamics

Microsoft Dynamics, Microsoft firması tarafından üretilen kurumsal çözüm yazılımları ailesi. 2005 yılından itibaren Microsoft Business Solutions ürün ailesinin yerini almıştır.
Microsoft Dynamics ailesi aşağıdaki ürünlerden oluşmaktadır:

Müşteri İlişkileri Yönetimi
Dynamics 365 Customer Engagement (CE) ( Eski Adi: Microsoft Dynamics CRM ) ayrıca aşağıdaki ürünlerde modüler olarak üyelik modeliyle piyasada bulunmaktadır.
Dynamics 365 Field Services
Dynamics 365 HR Management
Dynamics 365 Project Service Automation
Kurumsal kaynak planlama
Dynamics 365 Finance/Operation (F&O) ( Eski Adi: Microsoft Dynamics AX - Daha Eski adı: Axapta)
Dynamics 365 Business Central artik asagidaki 3 urun ailesini kapsamaktadir:
Microsoft Dynamics GP (Eski adı: Great Plains)
Microsoft Dynamics NAV (Eski adı: Navision)
Microsoft Dynamics SL (Eski adı: Solomon)
Satış Yönetimi
Microsoft Retail Management System (Eski adı: QuickSell)
