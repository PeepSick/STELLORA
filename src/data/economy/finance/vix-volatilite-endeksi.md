# VIX_volatilite_endeksi

Chicago Board Options Exchange Volatility Index (menkul değer sembolü: VIX), piyasalardaki korkunun derecesini ölçen bir endekstir. S&P 500 hisse opsiyon fiyatlarını kullanan VIX, opsiyon fiyatlarının piyasa volatilitesi ile ilişkisinden yola çıkarak piyasanın "beklenen volatilitesi"ni belirler.
